# 페이지별 의견 → 노션 '브로셔 의견' DB

브로셔 하단의 `의견` 버튼으로 들어온 수정 요청·의견이 노션 **브로셔 의견** DB에 행으로 쌓입니다.
브라우저는 노션에 직접 쓸 수 없으므로(토큰 노출·CORS) `Code.gs`를 Google Apps Script 웹앱으로 띄워 중계합니다.

```
브로셔 페이지 ──GET ?page=N / POST {page,name,text}──▶ Apps Script(Code.gs) ──노션 API──▶ 브로셔 의견 DB
```

- 노션 DB: `브로셔 의견` (컴인 홍보미디어국 1기 바로 아래). 속성: 내용(제목) · 페이지(숫자) · 이름 · 처리(체크) · 등록일
- 노션에서 **처리**에 체크하면 사이트에서 그 의견이 흐리게 표시되고 '✓ 반영'이 붙습니다.
- 토큰은 Apps Script의 스크립트 속성에만 둡니다. 저장소에는 절대 넣지 않습니다.

## 설정 (한 번만)

1. 노션에서 **브로셔 의견** DB 열기 → 오른쪽 위 `···` → **연결** → `레퍼런스 썸네일 봇` 추가
   (썸네일 봇과 같은 내부 연동을 재사용합니다. 안 하면 `404 object_not_found`)
2. https://script.google.com → **새 프로젝트** → 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs`를 붙여넣기 → 저장
3. 왼쪽 **프로젝트 설정(⚙)** → **스크립트 속성** → 속성 추가: 이름 `NOTION_TOKEN`, 값은 노션 내부 연동 시크릿
4. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 권한 승인(처음 한 번) → **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 복사
5. `index.html`의 `const FB_URL = '';` 안에 그 URL을 넣고 커밋 → `의견` 버튼이 켜집니다.

확인: 브라우저에서 `웹앱URL?page=1` 을 열면 `{"rows":[]}` 가 보여야 합니다.
`{"error":"Notion 404 …"}` 면 1번(연결)을, `{"error":"Notion 401 …"}` 면 3번(토큰)을 다시 확인하세요.

## 코드를 고쳤을 때

Apps Script는 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 바뀐 코드가 반영됩니다. URL은 그대로입니다.

## 한계

- 익명 등록이라 스팸 방지 장치는 없습니다. 문제가 되면 Apps Script 배포를 **보관처리**하면 즉시 막힙니다(사이트는 버튼만 사라짐).
- Apps Script 무료 한도(하루 UrlFetch 20,000회)는 의견 용도로는 충분합니다.
