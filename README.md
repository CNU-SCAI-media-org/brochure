# 컴퓨터인공지능학부 · 한학기 성과 모음 (웹)

주소는 이미 `https://cnu-scai-media-org.github.io/brochure` 로 채워져 있습니다.
아래 이름 그대로 올리면 추가 수정 없이 바로 동작합니다.

## 기능

- 특정 페이지 링크: 주소 끝에 `#p10` 을 붙이면 10페이지로 바로 열림
- `링크 복사` 버튼은 현재 보고 있는 페이지 주소를 복사
- 좌우 화살표 키 · 페이지 양옆 클릭 · 모바일 스와이프
- 하단 썸네일로 바로 이동
- `넘김 효과` 버튼으로 애니메이션 끄기
- 두쪽 보기에서는 실제 책처럼 낱장이 책등을 축으로 3D 회전하며 넘어감
  (표지는 오른쪽에 놓이고, 마지막 장은 왼쪽에 남는 실제 책 구조)
- `두쪽 보기` 버튼으로 펼침면(표지는 한 장, 이후 2·3, 4·5 …) 전환
  — 화면이 넓으면 자동으로 두쪽, 모바일은 한쪽으로 시작
- `PDF로 저장` 버튼으로 전체 페이지를 `brochure.pdf` 한 파일로 다운로드
  (`build.py` 실행 시 자동으로 다시 만들어집니다)

## 페이지를 교체하거나 추가할 때

원본 PDF를 `src/` 아래 목차 폴더에 넣고 빌드 스크립트를 한 번 실행하면 끝입니다.

```
src/
  01-표지/표지.pdf
  05-주요사업/01-SW중심대학.pdf, 02-BK21 plus.pdf, …
  10-동아리/01-동아리 성과.pdf, 02-동아리 · ANA · SPG.pdf, …
```

- 폴더 이름 앞 숫자가 **목차 순서**, 폴더 안 파일명 정렬이 그 안의 순서를 정합니다.
- 페이지 라벨(하단에 표시되는 이름)은 파일명에서 앞의 `NN-` 를 뗀 것입니다.
  파일명에 못 쓰는 `:` 는 전각 `：` 로 적으면 라벨에서 `:` 로 표시됩니다.
- 여러 페이지짜리 PDF도 그대로 넣으면 됩니다(모든 페이지가 같은 라벨).

실행:

```
python build.py
```

`pages/`, `thumbs/`, `brochure.pdf`, `index.html` 의 페이지 목록과 캐시 버전(`?v=N`)까지
전부 자동으로 다시 만들어 줍니다. 바뀐 것이 없으면 아무것도 다시 쓰지 않습니다.
필요한 것: Python 3 + `pip install pymupdf pillow`

`pages/`, `thumbs/` 는 생성물이므로 직접 수정하지 마세요.

## 미리보기가 안 뜰 때

카카오톡은 한 번 읽은 미리보기를 캐시합니다.
배포 전에 링크를 공유한 적이 있다면
카카오 개발자 도구(developers.kakao.com/tool/clear/og)에서 캐시를 지운 뒤 다시 공유하세요.

## 페이지를 고친 뒤 확실히 반영시키기

파일명이 같으면 브라우저·CDN 캐시 때문에 남들에게는 옛날 이미지가 보일 수 있습니다.
`build.py` 가 출력이 바뀔 때 캐시 버전(`?v=N`)을 자동으로 올려 주므로,
빌드 후 바뀐 파일을 전부 함께 커밋하기만 하면 됩니다.
